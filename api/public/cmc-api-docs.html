CMC API

CoinMarketCap-style JSON endpoints for indexed Omnipair pools. All routes are public GET, no auth. Responses are cached (~60s for most aggregates).

Base path: /api/v1/cmc
Pair id: baseMint_quoteMint — two Solana mint addresses separated by a single underscore (token order matches the pool’s token0 / token1).

GET /api/v1/cmc/factory

Omnipair program id on Solana (analogous to a factory).

Example
curl -s http://localhost:3000/api/v1/cmc/factory
Example response
{
  "factory": "3tJrAXnjofAw8oskbMaSo9oMAYuzdBgVbW3TvQLdMEBd",
  "network": "solana"
}

GET /api/v1/cmc/summary

Array of all visible pools with last price, spread (from fee), 24h volumes, high/low, and % change vs. open in the rolling 24h window.

Example
curl -s http://localhost:3000/api/v1/cmc/summary
Example response (snippet)

  {
    "trading_pairs": "So11111111111111111111111111111111111111112_EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v",

GET /api/v1/cmc/assets

Map of Solana mint address → metadata. unified_cryptoasset_id is the CoinMarketCap asset id when known (see src/config/cmcUnifiedCryptoassetIds.ts).

Example
curl -s http://localhost:3000/api/v1/cmc/assets
Example response (snippet)
{
  "EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v": {
    "name": "USD Coin",
    "unified_cryptoasset_id": "3408",
    "can_withdraw": "true",
    "can_deposit": "true",
    "contractAddress": "EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v"
  }
}

GET /api/v1/cmc/ticker

Map keyed by trading_pairs id: 24h volume, last price, CMC ids for base/quote mints.

Example
curl -s http://localhost:3000/api/v1/cmc/ticker
Example response (snippet)
{
  "So11111111111111111111111111111111111111112_EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v": {
    "base_id": "5426",
    "quote_id": "3408",
    "last_price": "142.5",
    "base_volume": "1200.5",
    "quote_volume": "171000.2",
    "isFrozen": "0"
  }
}

GET /api/v1/cmc/trades/:market_pair

All swaps in the last 24 hours for the pool identified by market_pair (URL-encoded mints with one underscore). No pagination — full window. Timestamps are Unix ms.

Example
curl -s "http://localhost:3000/api/v1/cmc/trades/So11111111111111111111111111111111111111112_EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v"
Example response (snippet)
[
  {
    "trade_id": 882341,
    "price": "142.51",
    "base_volume": "1.5",
    "quote_volume": "213.76",
    "timestamp": "1714924800000",
    "type": "buy"
  }
]
